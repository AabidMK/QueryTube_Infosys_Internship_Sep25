# Python Modules

This directory contains the main Python scripts for QueryTube's data pipeline and application services. Each file is designed for a specific step in the workflow:

## Data Collection and Processing

- **Yt_video_data_collection_task_1.py** 🟢  
  - Collects YouTube video/channel metadata using the YouTube Data API.
  - **Input:** API key (.env), channel ID (in script)
  - **Output:** Merges collected data to produce a CSV file of long-form videos and channel info.
  - Foundation for transcript extraction and all subsequent analysis.

- **transcripts.py** 💬  
  - Downloads transcripts (subtitles) for video IDs from the collected CSV.
  - **Input:** Video CSV (from above)
  - **Output:** CSV containing transcripts per video; supports robust retry and recovery.

- **EDA and Data_Quality_check_task_1.py & EDA_and_Data_Quality_Check_Task_2_Dataset.py** 📊  
  - Analyze and clean video information and transcript datasets, respectively.
  - **Input:** Processed video/transcript CSVs.
  - **Output:** Clean datasets, visual EDA plots, reports on missing data, duplicates, stats.
  - Guides improvements and readiness of data for further processing and downstream AI tasks.

## Embedding, Search, and API Integration

- **Search_Query_main.py** 🔍  
  - Implements semantic (meaning-based) search using embeddings + ChromaDB vector store.
  - **Input:** ChromaDB database, embedding model, processed data.
  - **Output:** Returns top matching videos for a textual query (used by backend APIs).

- **ai_app.py** 🌐  
  - Flask-based web server to serve the main user interface (UI) and expose `/search` API endpoint to the frontend.
  - **Input:** Calls the semantic search logic; connects to the ChromaDB via Search_Query_main.py.
  - **Output:** HTML UI in browser, JSON search results for web or programmatic access.

- **api.py** 🚀  
  - Alternative backend using FastAPI—serves as a JSON-based semantic search API.

- **__pycache__/** ⚙️  
  - Compiled Python files (autogenerated; can be ignored for all practical purposes).
