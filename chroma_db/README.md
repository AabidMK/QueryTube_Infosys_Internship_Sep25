# chroma_db

This directory holds the persistent vector database files required by ChromaDB.

- ChromaDB provides high-performance vector search capabilities for QueryTube's semantic retrieval features.
- All models, embeddings, and similarity indexes used for search are indexed, stored, and retrieved from this location.
- The files inside are managed automatically by the embedding/semantic search scripts and services; no manual intervention is necessary for day-to-day use.
