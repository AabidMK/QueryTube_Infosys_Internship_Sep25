Steps to RUN the AI QUERYTUBE in the local system
-----------------------------
If you're using a Virtual Environment then use "venv\Scripts\Activate"
-----------------------------
STEP 1 : >> pip install -r requirements.txt
-----------------------------
STEP 2 : >> python load_data_chroma.py
-----------------------------
STEP 3 : >> python search_engine.py
-----------------------------
STEP 4 : >> uvicorn app:app --reload
-----------------------------
STEP 5 : >> Wait for the backend to start open the index.html file
-----------------------------
STEP 6 : >> Now the Frontend is up and the backend is running perfectly.
-----------------------------
