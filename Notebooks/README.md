# Notebooks

This directory contains Jupyter notebooks designed for interactive data analysis, prototyping, and workflow documentation within the QueryTube project.

## Contents
- **master_datasets_cleaned.ipynb**  
  Stepwise notebook for cleaning, merging, and verifying main YouTube video datasets. Facilitates visual inspection and validation early in the data pipeline.

- **Merged_Embeddings_Searchquery.ipynb**  
  Demonstrates embedding generation for transcripts/videos and provides example code for executing semantic search queries against the embedding index.

## Usage
- Notebooks are best launched with JupyterLab, Jupyter Notebook, or a compatible IDE (e.g., VS Code with the Python extension). They provide an interactive, iterative environment for custom analysis and rapid experimentation outside the automated pipeline.
